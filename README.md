# 拳の間 — KEN NO MA

酔拳と詠春拳で対戦する、ポリゴン調のブラウザ3D格闘ゲームです。

## ブラウザで遊ぶ

**[▶ 今すぐ遊ぶ — PLAY](https://drunken-wing.jizomae.chatgpt.site)**

インストール不要です。リンクを開き、流派を選んで「対戦開始」を押してください。公開ページはURLから誰でもアクセスできます。

JavaScriptとWebGLで動きます。ビルド作業、追加ライブラリ、外部素材のダウンロードは不要です。中庭・人物・アニメーション・効果音はコードから生成しています。

## 遊び方

1. 酔拳または詠春拳を選び、「対戦開始」を押します。
2. CPUと対戦し、2ラウンド先取で勝利です。
3. 効果音は画面右上の「音 OFF」から有効にできます。

| 操作 | キー |
| --- | --- |
| 左右に移動 | A / D または ← / → |
| 奥・手前に軸移動 | W / S または ↑ / ↓ |
| 拳撃 | J。連続入力で三連撃 |
| 蹴り | K |
| 奥義 | L。氣が100%のとき発動 |
| ガード | Spaceを長押し |
| 一時停止・再開 | Esc |

画面上のボタンでも操作できます。

- 1ラウンド60秒。体力がなくなるか、場外に出るとラウンド敗北です。
- 時間切れは残り体力で判定します。同点は引き分けです。
- ガード中は被ダメージを抑えられます。奥義はガードを崩します。
- 攻撃や被弾で氣が溜まります。

## ローカルで起動

Python 3と、WebGLを使用できるブラウザが必要です。

このフォルダで次のコマンドを実行します。

```sh
python -m http.server 8000 --directory dist
```

環境によっては `python` を `python3` に置き換えてください。

ブラウザで <http://localhost:8000> を開くと遊べます。終了するときはターミナルで `Ctrl+C` を押してください。

ES modulesを使用しているため、HTMLファイルのダブルクリックではなくHTTPサーバー経由で開いてください。ゲームの配信にNode.jsは不要です。

## 配信

`dist/` の中身を静的サイトとして配信できます。`index.html`、CSS、JavaScriptを同じフォルダ構成のまま配置してください。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `dist/index.html` | 選択画面・体力表示・操作ボタン |
| `dist/style.css` | 画面デザインとスマートフォン対応 |
| `dist/engine.js` | WebGL描画と行列計算 |
| `dist/scene.js` | 中庭・人物・動き・ヒット演出 |
| `dist/combat.js` | 攻撃判定・CPU・ラウンド進行 |
| `dist/game.js` | 入力・画面更新・効果音 |
| `test_combat.mjs` | 戦闘処理と座標計算のテスト |

`dist/` 内が編集可能なソースコードです。自動生成されたビルド成果物ではありません。

## テスト

Node.js 18以降で実行できます。依存パッケージのインストールは不要です。

```sh
node test_combat.mjs
```

または `npm test` を実行してください。

単発ヒット、ガード、距離・向き、両流派の奥義、ラウンドのリセット、場外、時間切れ、一時停止、試合結果、CPUの攻撃、描画座標が有限値になることを確認します。ブラウザでの表示や実機の動作速度を確認するテストは含みません。
